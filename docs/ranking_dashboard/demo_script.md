# Demo Script - Module 5
1. **Khởi động**: Đăng nhập tài khoản Admin -> Xem Dashboard (9 cards thống kê hệ thống).
2. **Dashboard Hội đồng (Board)**: Đăng nhập Board -> Xem Dashboard (Tổng xếp hạng, Manga đã/chưa chấm).
3. **Tạo Xếp hạng (Ranking)**: Board tạo Xếp hạng mới -> Kiểm tra Validation (điểm số, vị trí xếp hạng).
4. **Dashboard Biên tập viên (Editor)**: Đăng nhập Editor -> Kiểm tra số liệu Bản thảo chờ duyệt, Đã duyệt, Bị từ chối.
5. **Dashboard Tác giả (Mangaka)**: Đăng nhập Mangaka -> Thấy thống kê Submissions, Pending Reviews. Kiểm tra thông báo mới và thử click Đánh dấu đã đọc (sử dụng POST form bảo mật).
